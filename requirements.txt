# **不要装 torchvision / torchaudio。**
#
# 本仓库一行都没引用它们（纯文本框架，用不到视觉 / 音频）。但 transformers
# >=4.51 在导入任何建模类时会连带 import transformers.loss -> image_utils ->
# torchvision，而那道守卫只看「这个包在不在」（find_spec，不试导入）。于是只要
# 它装着、且与 torch 版本对不上，**所有**模型都导不进来，报错还完全看不出原因：
#
#     RuntimeError: operator torchvision::nms does not exist
#     ModuleNotFoundError: Could not import module 'Qwen2ForCausalLM'   <- 被裹了一层
#
# 典型来源：装过 CUDA 版的 torchvision/torchaudio，之后单独升级了 torch ——
# 这两个伴生包各自 pin 死了旧 torch 的**精确**版本，于是 ABI 对不上。检查与处理：
#
#     python -m pip list | grep -iE "^(torch|torchvision|torchaudio) "
#     python -m pip uninstall -y torchvision torchaudio
#
# 三个版本号必须一致；不一致就卸掉，不要试图去「修」它。真需要它们（比如另一
# 个项目要用视觉），那也得与 torch 同版本一起装。
